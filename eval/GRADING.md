# How to grade a run

1. Run setup in a session that has never seen `eval/ANSWER-KEY.md`.
2. Save that session's outputs: `STACK.md`, `ONCALL.md`, the drafted
   `skills/triage/references/*.md`, `lessons.md`, `alert-coverage.md`, and
   the Phase 3 grading table.
3. In a **separate** session, hand over the answer key and those outputs
   only - never the transcript of the run.
4. Score each planted finding: found / partial / missed.
5. A miss is a bug in the skill's wording, not in the run. Fix the skill,
   start from a clean clone, run again.
